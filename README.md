# 투자 알림 PWA

## 로컬 실행
```
npm install
npm run dev
```

## Vercel 배포 (무료)
1. vercel.com 가입
2. GitHub에 이 폴더 업로드
3. Vercel에서 Import → Deploy

## iPhone 홈 화면에 추가
1. Safari로 배포된 URL 접속
2. 하단 공유 버튼 탭
3. "홈 화면에 추가" 선택
4. 앱처럼 사용 가능!

## API Key 설정
src/services/stockService.js 파일에서
YOUR_APP_KEY, YOUR_APP_SECRET를 실제 키로 교체하세요.
